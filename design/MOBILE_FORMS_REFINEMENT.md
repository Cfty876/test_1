# Формы и мобильный кабинет — 1 ноября 2026

Сохранены Pervye Book / Extended, красно-белый бренд и существующие права, маршруты и данные. Это доработка действующей системы, новая визуальная система не вводилась.

- Боковое меню: убран повтор полного названия Совета в подвале. Логотип и официальное название остаются сверху. Само меню не прокручивается целиком; на низком экране прокручивается только список разделов. Помощь остаётся доступной.
- Обе анкеты: общий выбор направлений в одну колонку, обычный текстовый шрифт, подписи под названиями. Отдельные колонки для переключателя и текста, без фиксированной высоты текста. Между группами заданы явные отступы вместо сочетания вложенного fieldset и универсальных внешних отступов. Сохранены одиночный/множественный выбор, клавиатура, ошибки рядом с полями и обязательное согласие.
- На телефоне профиль открывается круглой кнопкой 44px с аватаркой 40px. Полное имя остаётся в доступном названии и самом профиле. Экран редактирования фото также компактнее, выбор области и сжатие сохранены.
- В школьном кабинете короткие заголовки; школа указана отдельной строкой с адаптацией текста. Убраны повторные рекламные переходы к каталогу и рейтингу с главного экрана телефона; эти разделы доступны в нижней навигации. События, проекты и баллы остаются на главной.
- В каталоге короткие вкладки «Идеи» / «Команда». На телефоне направления раскрываются кнопкой с текущим значением. Все фильтры и счётчики сохранены, на компьютере видны сразу. Уменьшены отступы и вторичные элементы без уменьшения областей нажатия ниже 44px.

Использованы локальные UI UX Pro Max (не обрезать важное содержимое, сохранять навигацию), Taste/app screens (плотность и устройство мобильных рабочих экранов), Awesome Claude Design/editorial/linear (иерархия и спокойные поверхности; чужая палитра не переносилась), React Best Practices. Новые анимации и зависимости не добавлены; существующий reduced motion сохранён. Поиск рекомендаций React по адаптивности не дал проверенного совпадения, решения взяты из перечисленных UX-источников и существующего кода.

21st изучен только на уровне метаданных: Bottom Menu, 0xUrvish; Mobile Navigation Tabs, shadcnui-blocks. Код не получался и не копировался, платная генерация не использовалась.

Проверка: типы, production-сборка и проверки общих направлений/React SSR. Computer Use и его нативный Windows-вариант вернули `failed to write kernel assets (os error 3)`. Поэтому фактическая вёрстка в браузере, жесты и вид на конкретном телефоне пока не подтверждены. SSR проверяет структуру, а не изображение страницы.
