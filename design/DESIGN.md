# Первик / Город делают люди

Отдельный интерактивный прототип. Production не заменяется.

## Идея

Городской плакат переходит в рабочую платформу. Главная даёт подростку смелость предложить свою идею, каталог помогает найти дело по силам, кабинет помогает сотруднику принять следующее решение.

Собственные опоры: Екатеринбург; школьные советы; авторство ребят; четыре направления; переход от школы к городу; поддержка партнёра; лайки и поиск команды; подтверждённые реализации; собственный логотип Первика; красно-белая идентичность; доступность публичной доски без регистрации.

## Визуальная система

- Фон #FAFAF8 / белые поверхности, текст #202024, красный #DF002B, спокойная вторичная поверхность #F0F0ED.
- Manrope, кириллица, локальные шрифты. Заголовки крупные, естественный регистр; кабинет 24–32px, основной текст 16px.
- Единые поля 24px на телефоне, 48px на компьютере; максимальная ширина 1440px. Отступы кратны 4/8.
- Кнопки 48–56px, прямоугольная форма с небольшим радиусом. Круглая форма только у компактных иконок/аватаров.
- Красный используется для основного действия и смыслового акцента. Статусы содержат текст, а не только цвет.
- Публичная страница открывается крупным двухстрочным высказыванием; фото появляется ниже в отдельной редакционной секции.
- Каталог и кабинет имеют повторяемые карточки/строки как функциональные объекты. Маркетинговые блоки не превращаются в сетку одинаковых карточек.

## Интерактивный охват

Главная, каталог, проект, кабинет с переключением четырёх ролей, вход в демо, подача инициативы. Лайки пересчитывают порядок. Поиск/фильтры имеют пустое состояние. Заявки в кабинете можно раскрывать и принимать в памяти прототипа. Права в демо определяются выбранной ролью: председатель видит базу и реализации, куратор принимает заявки, партнёр видит только переданные инициативы.

Вся информация вымышлена и отмечена как демонстрационная; API действующего сайта не вызывается. Демо-вход не собирает пароли. Заявка не отправляется наружу, контакты не запрашиваются. Счётчики вычисляются из массива, выбранные лайки сохраняются только в памяти вкладки.

## Источники решений

- UI UX Pro Max: локальный поиск nonprofit youth community выбрал Minimalism & Swiss Style. Рекомендация фиолетовой палитры отклонена как несовместимая с заданной красно-белой идентичностью; генератор не использован как источник фактов о продукте.
- Taste: `type-only-statement`, seed 1905217177, без повторных подборов; пропорции и типографическая композиция адаптированы под длинную кириллицу и навигацию сервиса. Каталог проектов и рабочие экраны следуют app-screen правилам. Референс не диктует скрывать полезный интерфейс или отключать масштаб.
- Awesome Claude Design: editorial/linear, editorial/vercel и remix/notion-x-duolingo: читаемость, рабочая плотность и дружелюбная реакция элементов, без заимствования чужого брендинга.
- 21st: Motion Navigation Menu by unlumen, https://21st.dev/@unlumen/components/motion-navigation-menu ; Animated Project Cards by isaiahbjork, https://21st.dev/@isaiahbjork/components/animated-project-cards . Код получен через официальный MCP в рамках двух бесплатных получений 24 октября 2026. Использованы принципы активного индикатора и раскрывающейся карточки; реализация прототипа самостоятельная, исходники авторов не распространяются.
- Design Motion Principles: Jakub для переходов 220–360ms, Emil для быстрых рабочих действий. Framer Motion: layoutId и layout для сохранения пространственной связи, AnimatePresence для панелей. Reduced motion отключает перемещение. Нет бесконечного декоративного движения, GSAP и второй движок не добавляются.

## Граница между демонстрацией и production

Переключение ролей — инструмент прототипа, не система авторизации. Перед переносом нужны утверждение направления, привязка к реальным API и серверным правам, состояния загрузки/ошибок реального сервера и согласование текстов. Не публиковать этот прототип вместо платформы автоматически.
