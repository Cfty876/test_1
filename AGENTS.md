# Первик — правила работы над интерфейсом

Эти правила относятся только к этому репозиторию. При работе над визуалом использовать установленные здесь навыки, а не устанавливать их глобально.

## Обязательные источники для дизайн-задач

1. `.agents/skills/ui-ux-pro-max/SKILL.md`: композиция, доступность, адаптивность, типографика и рекомендации для React. Перед новой визуальной системой выполнить локальный поиск `--design-system`; использовать результат как рекомендацию с учётом бренда.
2. `.agents/skills/design-taste-frontend/SKILL.md`: самостоятельная арт-дирекция, осмысленная композиция и просмотр результата. Для кабинетов прочитать его `references/app-screens.md`.
3. `.agents/skills/design-motion-principles/SKILL.md`: намеренная анимация. Публичная часть: аккуратная выразительность Jakub; рабочие кабинеты: сдержанность Emil. Библиотека `framer-motion`, уже присутствующая в зависимостях через Motion; не подключать второй анимационный движок без необходимости. Уважать reduced motion. Не анимировать ввод, не блокировать действия эффектами.
4. `.agents/skills/21st-ui/SKILL.md`: искать подходящие референсы 21st перед созданием новых больших блоков. Использовать доступные MCP-инструменты либо `node scripts/design-tools/21st.mjs`. Не считать поиск получением исходного кода. Проверять лицензию/доступ к коду, сохранять авторство. Не обходить платные ограничения и не запускать платную генерацию автоматически.
5. `design/references/awesome-claude-design/`: библиотека материалов и дизайн-приёмов. Это референсы, а не отдельный исполняемый продукт. Выбирать подходящие материалы, не смешивать все стили сразу.

## Приоритеты проекта

- Красно-белая идентичность, собственный SVG-логотип «Первик», русский язык, Екатеринбург.
- Участник предлагает идею, находит команду и следит за заявкой; сотрудники работают с заявками и реализациями согласно своим правам.
- Не подменять реальную статистику вымышленными числами. В отдельном прототипе явно обозначать демонстрационные данные и изолировать действия от production API.
- Прототип редизайна находится в `design/prototype/`. Не переносить его в действующий интерфейс и не деплоить вместо платформы без запроса пользователя.
- Сначала читать `design/DESIGN.md`, использовать единые токены. Не ломать существующие маршруты, права, формы и доступность.
- Мобильный интерфейс проектировать отдельно: 44px для касаний, safe area, переносы, минимальная навигация, отсутствие горизонтальной прокрутки. Не запрещать масштабирование браузера.
- Не запускать сторонние браузерные инспекторы/CDP-скрипты навыков: для управления браузером использовать доступный Computer Use. Не добавлять и не запускать тесты без запроса пользователя.

## Секреты и источники

- Ключ 21st хранится только в игнорируемом `.env.design-tools.local` и локальном `.codex/config.toml`. Не выводить ключ, не добавлять `VITE_` к имени, не отправлять в клиент, GitHub или Vercel.
- Коммитить исходники навыков, лицензии и `design/TOOLS.lock.json`. Обновлять осознанно по официальным источникам.
- Перед коммитом учитывать существующие незакоммиченные изменения пользователя. Добавлять только файлы текущей задачи, не использовать `git add .`.
